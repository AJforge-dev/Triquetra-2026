Generative AI

Autonomous Multi-Agent Systems & LLMs

Background

The advent of reasoning models, open-weight LLMs, and agentic workflows has revolutionized automated problem-solving. Autonomous AI swarms can collaborate to analyze complex codebases, execute distributed research, and synthesize actionable intelligence without constant human intervention.

Objective

Develop an autonomous multi-agent system utilizing open-weight LLMs or fine-tuned reasoning models capable of executing multi-step complex workflows with robust self-correction.

Solution Scope
  • Orchestration of specialized autonomous sub-agents with role division
  • Integration of local/open-weight LLMs (DeepSeek, Llama 3) or API models
  • Retrieval-Augmented Generation (RAG) with vector databases for knowledge grounding
  • Self-reflection, chain-of-thought verification, and automated error-correction loops
  • Interactive chat or task-dashboard for real-time human-in-the-loop oversight
Evaluation Parameters
  • Agent autonomy, reasoning depth, and task completion success rate
  • Handling of tool-calling, API integration, and unexpected execution failures
  • Inference efficiency, context window utilization, and latency optimization
  • Novelty of agentic coordination architecture
  • Practical utility for enterprise workflows, software engineering, or research
Expected Outcome

A functional, autonomous multi-agent application demonstrating intelligent delegation, tool execution, and dependable reasoning.

Build autonomous sub-agents with role division, vector database retrieval, and self-correcting reasoning loops.

EVALUATION PROTOCOL

Judging Criteria

How the AI & DS faculty jury and technical experts will evaluate your hackathon solutions.

Algorithmic Innovation

Novelty of the model architecture, prompt engineering, agentic coordination, or data engineering pipeline.

Technical Implementation

System architecture quality, code cleanliness, modularity, and effective use of modern AI frameworks (PyTorch, LangChain, HuggingFace, TensorRT).

Prototype Completeness

The project must be a functional end-to-end working prototype with operational models and interactive UI, not solely static slides.

Latency & Scalability

Inference speed, context management, resource consumption, and ability to handle high throughput data streams.

Practical Impact & Ethics

Effectiveness in addressing genuine industry problems, hallucination safeguards, and fairness of results.

Presentation & Live Demo

Clarity in explaining the mathematical intuition, live inference demonstration, and technical defense during Q&A.
